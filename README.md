## Описание работы

Проект является продолжением лабораторной работы №1 про платформу обработки задач.
Архитектура источников задач и приёмника сохранена, а во второй лабораторной
переработана сама доменная модель `Task`.

---

## Что изменилось

Во второй лабораторной реализованы:

- пользовательские дескрипторы для валидации атрибутов;
- вычисляемые свойства через `@property`;
- специализированные исключения для нарушений инвариантов;
- разделение публичного API и внутреннего состояния;
- демонстрация различий между data descriptor и non-data descriptor.

---

## Модель `Task`

Задача теперь содержит:

- `id`;
- `description`;
- `priority`;
- `status`;
- `created_at`;
- вычисляемые свойства `is_ready_for_execution` и `is_finished`.

Для обратной совместимости с первой лабораторной сохранён `payload` как property-алиас
к `description`.
